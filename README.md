# ephemeris

## Go Based Calendar Library

The `ephemeris` library is a Go-based tool for managing and organizing events with respect to time. It provides functionality for creating, repeating, skipping, and canceling events. The library allows users to view events within a specified timeframe, condensing overlapping events based on priority.

## Features

- **Event Management**: Create and manage events with start and end times.
- **Repeating Events**: Define rules for recurring events (e.g., daily, weekly, annually).
- **Skipping and Canceling Events**: Specify times when events should be skipped or canceled.
- **Viewing Events**: Retrieve a list of events within a given timeframe, considering all repeating rules.
